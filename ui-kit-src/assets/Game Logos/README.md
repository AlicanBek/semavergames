Every game has its own logo, built on one pattern so the games read as a family under Semaver Games.

The pattern:
- The red plaque with pointed ends and a bowed top and bottom, taken from the Yanık Masası build: three-stop red gradient, 1.5px gold edge, faint inner line, gloss on the top half, dark lip underneath.
- The game's name in Montserrat 900 capitals, cream with a dark red shadow, on one or two lines, centered on the plaque. The lettering is outlined.
- The game's emblem on both sides, mirrored and tilted outward about 9 degrees, overlapping the ends of the plaque.

| File | Game | Emblem |
|---|---|---|
| `game-yanik-masasi.svg` | Yanık Masası | A playing card with a spade, on fire |

The emblem is also available on its own, for places where the name is already present (the ends of the play banner, loading screens, empty states):

| File | What |
|---|---|
| `emblem-yanik-card-left.svg` | The flaming card, tilted left. Goes on the left side. |
| `emblem-yanik-card-right.svg` | The mirrored card, tilted right. Goes on the right side. |

Rules:
- One file works on both dark and light grounds; the plaque carries its own background.
- A new game changes only the name and the emblem. Keep the plaque shape, the lettering style and the mirrored layout.
- A game may recolor the plaque with its own theme's `primary-` stops. The gold edge stays.
- Minimum width 140px. Below that, use the emblem alone.
- The Semaver Games logo and a game logo are never merged into one drawing. Where both appear, the game logo leads and "Semaver Games" sits small beneath or in a corner.
