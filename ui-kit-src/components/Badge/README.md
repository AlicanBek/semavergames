Small markers that something is waiting or new.

- `sg-badge`: a count on a nav item (unclaimed gifts, friend requests). Show the number up to 99.
- `sg-badge--dot`: something is new but there is nothing to count. Give it an `aria-label`.
- `sg-ribbon`: a word on a card corner. Only two words are used: "Yeni" and "Yakında".

You provide: the count or the word. Remove the badge as soon as the player has seen or claimed the thing; a badge that never clears stops meaning anything.
